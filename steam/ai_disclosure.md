## Live-Generated (made by AI while the app runs)
**English**
GAFIL's chat answers are generated in real time by Anthropic's Claude models through the Claude Code tool, using the player's own Anthropic API key. Output is text only; GAFIL does not generate images, audio or video with AI.
Guardrails:
- Claude models follow Anthropic's safety training and Usage Policy, which prohibit illegal and sexual content involving minors and other harmful content. GAFIL does not include any adult content.
- Generated text is shown only to the player on their own PC. It is never posted or shared with other players.
- Any action on the PC requires the player's explicit approval: every command, every file change, and screen control once per task (with a red border and an emergency stop; moving the mouse stops it immediately).
- Players can report problems on the project's issue tracker: https://github.com/steeze1213/GAFIL/issues
