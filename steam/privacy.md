# GAFIL privacy notice (Steam edition) / 개인정보 안내 (Steam 배포판)

**English**
- GAFIL has no servers and collects no data. There are no analytics, ads or tracking.
- When you ask GAFIL something, it runs Anthropic's Claude Code on your PC with your own API key. Your question, any files or text you give the cat, command results, and screenshots taken during screen control are sent to Anthropic and handled under Anthropic's privacy policy: https://www.anthropic.com/legal/privacy
- Your API key is stored only in your Windows user environment variable `ANTHROPIC_API_KEY`. GAFIL does not send it anywhere else or write it to its logs.
- Settings, chat history, reminders and the command log stay on your PC in `%LOCALAPPDATA%\ClaudeDesk`. Delete that folder to remove them.
- The Steam edition does not check GitHub for updates; Steam handles updates.
- Body-language alerts, quick answers, CPU/GPU display and everything the cat does on its own run locally and send nothing.
- Voice input uses Windows voice typing (Win+H). Speech is processed by Microsoft under Windows' own privacy settings, not by GAFIL.

**한국어**
- GAFIL에는 서버가 없고, 어떤 데이터도 모으지 않습니다. 분석, 광고, 추적이 없습니다.
- 질문하면 GAFIL은 본인 PC의 Claude Code를 본인의 API 키로 실행합니다. 질문, 고양이에게 준 파일이나 글, 명령 실행 결과, 화면 조작 중 스크린샷은 Anthropic으로 전송되며 Anthropic의 개인정보 처리방침을 따릅니다: https://www.anthropic.com/legal/privacy
- API 키는 Windows 사용자 환경 변수 `ANTHROPIC_API_KEY`에만 저장됩니다. GAFIL은 키를 다른 곳으로 보내거나 로그에 남기지 않습니다.
- 설정, 대화 기록, 알림, 명령 로그는 본인 PC의 `%LOCALAPPDATA%\ClaudeDesk`에만 있습니다. 이 폴더를 지우면 모두 지워집니다.
- Steam 배포판은 GitHub에서 업데이트를 확인하지 않습니다. 업데이트는 Steam이 맡습니다.
- 몸짓 알림, 바로 답하기, CPU/GPU 표시 등 고양이가 혼자 하는 일은 모두 PC 안에서만 동작하며 아무것도 보내지 않습니다.
- 말로 하기는 Windows 음성 입력(Win+H)을 씁니다. 음성은 GAFIL이 아니라 Microsoft가 Windows 개인정보 설정에 따라 처리합니다.
