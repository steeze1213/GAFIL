# Steam 스토어 페이지 — 한국어

Steamworks → 스토어 페이지에서 언어를 한국어로 바꾸고 각 칸에 붙여 넣으세요. "게임 정보" 칸은 Steam BBCode 형식입니다.

## 앱 이름
GAFIL

## 짧은 설명 (300자 이내)
바탕화면에 사는 작은 픽셀 고양이. 창 위를 돌아다니고, Claude로 질문에 답해요. 명령과 화면 조작은 항상 먼저 물어보고, 간단한 계산과 단위 변환은 PC에서 바로 답해요. Claude Code와 본인의 Anthropic API 키가 필요해요.

## 게임 정보
```
[h2]진짜로 도와주는 책상 위 고양이[/h2]
GAFIL은 화면 아래를 돌아다니는 작은 픽셀 고양이예요. 고양이를 클릭해서 물어보면 Anthropic의 Claude로 답해요. 간단한 질문부터 PC에서 하는 실제 작업까지.

[h2]할 수 있는 것[/h2]
[list]
[*][b]Claude와 대화[/b] — 답이 작은 말풍선에 타이핑되듯 나와요. 어디서든 Ctrl+Alt+G로 불러요.
[*][b]진짜 작업, 내 허락을 받고[/b] — 명령 실행, 폴더 정리, 파일 수정. 명령이나 파일 변경 전에는 매번 승인 창이 떠요.
[*][b]화면 조작[/b] — 화면을 봐야 하는 일도 해요. 작업마다 한 번 묻고, 빨간 테두리를 보여 주고, 마우스를 움직이면 바로 멈춰요.
[*][b]바로 답하기, 토큰 0[/b] — 계산, 퍼센트, 단위 변환, 다른 도시 시각, D-day는 Claude를 부르지 않고 PC에서 계산해요.
[*][b]알림[/b] — "30분 뒤에 알려줘" 하면 시간이 됐을 때 고양이가 화면 가운데로 뛰어와요.
[*][b]파일 끌어다 주기[/b] — 파일이나 글을 고양이에게 끌어다 놓고 요약해 달라고 해 보세요.
[/list]

[h2]그리고 고양이예요[/h2]
[list]
[*]창 위로 뛰어오르고, 창 옆을 기어오르고, 창 윗변에 엎드려 꼬리를 늘어뜨려요.
[*]작은 창이 새로 뜨면 상자인 줄 알고 쏙 들어가요. 목덜미를 잡아 옮기면 그루밍, 조용하면 꾹꾹이.
[*]몸짓 알림: 오류 창 위에 앉고, 멈춘 앱을 앞발로 툭툭, 오래 일하면 드러누워요.
[*]CPU가 바쁘면 헥헥, GPU가 뜨거우면 땀, 밤에는 꾸벅꾸벅.
[*]털 색 5가지, 옷 4가지, 그리고 친해지면 알려 주는 비밀 몇 가지.
[/list]

[h2]PC에 가볍게[/h2]
단순한 픽셀 그림이라 무겁지 않아요. 10분 동안 아무것도 묻지 않으면 Claude 프로세스를 꺼서 메모리를 돌려줘요. 게임할 때도 부담 없어요.

[h2]시작하기 전에[/h2]
[list]
[*]GAFIL은 [b]Claude Code[/b](Anthropic의 무료 명령줄 도구)가 필요해요. 처음 켜면 버튼 하나로 설치할 수 있어요.
[*]GAFIL은 [b]본인의 Anthropic API 키[/b]로 연결돼요. Claude 사용 요금은 Anthropic이 본인 계정에 청구하고, GAFIL은 무료이며 따로 받는 돈이 없어요.
[*]질문, 고양이에게 준 파일, 명령 실행 결과, 화면 조작 중 스크린샷은 Claude Code를 쓸 때처럼 Anthropic으로 전송돼요.
[/list]

GAFIL은 Anthropic과 관련이 없는 비공식 프로젝트이며 Anthropic이 승인하지 않았습니다. "Claude"는 Anthropic, PBC의 상표입니다.
```
